## 🛠️ Tech Stack & Arsitektur
- **Framework:** [React 19](https://react.dev/) + [Vite](https://vite.dev/)
- **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)

- **Theme:** Sleek Tech Dark Minimalist (Vercel/Linear inspired aesthetic) with responsive glassmorphism

## 💻 Menjalankan di Lokal (Development)

Pastikan Node.js (>= 18) sudah terinstal:

```bash
# 1. Clone repositori
git clone https://github.com/kulitechid/kulitech.github.io.git
cd kulitech.github.io

# 2. Instal dependensi
npm install

# 3. Jalankan server lokal
npm run dev
```

Buka `http://localhost:5173` di browser Anda.

---

## 📦 Build untuk Produksi

```bash
npm run build
```
File output siap saji akan dibuat di folder `dist/`.

---

## 🚀 Setup GitHub Pages (Otomatis)

1. Buka repositori di GitHub: [https://github.com/kulitechid/kulitech.github.io](https://github.com/kulitechid/kulitech.github.io)
2. Buka tab **Settings** $\rightarrow$ **Pages** (di sidebar kiri).
3. Di bagian **Build and deployment** $\rightarrow$ **Source**, pilih **GitHub Actions**.
4. Setiap kali Anda melakukan `git push origin main`, GitHub Actions akan otomatis mem-build dan men-deploy website ke `https://kulitechid.github.io/`.
